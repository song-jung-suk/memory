## 🖼️ 핵심 썸네일 시안: 마진을 갉아먹는 숨겨진 비용 (The Hidden Costs)

### 1. 시각 컨셉 요약 (Concept Summary)
**핵심 전략:** 화면을 좌우 또는 상하로 명확하게 분할하여 '손실(Chaos)'과 '해결책(Order)'의 극단적인 대비를 통해 심리적 충격을 유발합니다.

### 2. 디자인 가이드라인 (Design Guidelines)

| 요소 | Chaos 영역 (불안/손실 - Red Dominant) | Order 영역 (해결/시스템 - Blue Dominant) |
| :--- | :--- | :--- |
| **배경 색상** | `#D90429` (강렬한 빨강, 위협감) | `#1A53FF` (신뢰감 있는 파랑, 안정감) |
| **주요 폰트** | **Chaos:** 'Impact' 또는 유사하게 각지고 불안정한 산세리프체. | **Order:** 'Noto Sans KR Bold' 또는 'Pretendard SemiBold' (깔끔하고 신뢰감 있는 서체). |
| **레이아웃** | 화면 왼쪽 60%를 차지하며, 심각한 손실을 나타내는 시각적 요소 배치. | 화면 오른쪽 40%를 차지하며, 명확한 해결책과 시스템을 제시하는 구조화된 레이아웃 배치. |
| **핵심 이미지/아이콘** | 돈이 새는 모습 (물방울), 빨간색 화살표(하향), 깨진 그래프, 'X' 표시 등 혼란스러운 시각적 노이즈. | 깔끔한 차트, 상승하는 그래프, 자물쇠 아이콘, 명확한 체크리스트/시스템 구조도. |
| **텍스트 배치** | 큰 폰트로 "마진 파괴" 또는 "숨겨진 비용"을 강렬하게 배치하여 즉각적인 불안 유발. | 작은 폰트로 구체적인 해결책의 키워드(예: '3가지 비용 공개', '수익 복구 시스템')를 명확히 제시. |
| **전환선** | 두 영역 사이에는 날카로운 대각선 또는 불규칙한 선으로 경계를 설정하여 시각적 충돌을 극대화합니다. |

### 3. 최종 레이아웃 좌표 (Layout Coordinates - 예시)
*   **전체 비율:** 16:9 (유튜브/쇼츠 표준)
*   **Chaos 영역 (좌측):** X축 0% ~ 50%
*   **Order 영역 (우측):** X축 50% ~ 100%

### 4. 최종 디자인 컨셉 설명 (Visual Narrative)
화면 왼쪽(Red Chaos)에는 마진이 사라지는 듯한 어둡고 혼란스러운 시각적 표현을 배치하여 시청자의 **불안감과 손실 인지**를 즉시 유발합니다. 화면 오른쪽(Blue Order)에는 그 혼란 속에서 발견한 명확하고 구조화된 '숨겨진 비용 3가지'와 '수익 복구 시스템'이라는 **명쾌한 해결책**을 파란색의 깔끔한 데이터와 시스템으로 제시하여 시청자에게 즉각적인 신뢰감과 행동 동기를 부여합니다.
