# Tier 1 비주얼 에셋 초기 초안 (Chaos $\rightarrow$ Order 적용)

## 1. [영상 A] 혼돈에서 질서로의 전환
*   **컨셉:** 화면 좌측 60%는 강렬한 Red(혼돈, 불안정성, 복잡한 데이터 시각화). 화면 우측 40%는 차분한 Blue(질서, 명확한 해결책, 깔끔한 UI 디자인).
*   **레이아웃 좌표:** 수직 중앙선을 기준으로 좌우로 극단적인 색상 대비를 설정.
*   **핵심 요소:** 복잡하게 얽힌 선과 데이터 흐름(Red)이 명확한 그리드와 정렬된 인터페이스(Blue)로 정리되는 시각적 전환점 강조.

## 2. [영상 B] 시스템 정복의 과정
*   **컨셉:** Red 색상을 배경으로 전체 화면을 채우되, 중앙에 Blue의 빛줄기나 깔끔한 도형이 'Order'를 상징하며 혼돈 속에서 질서를 찾아내는 시각화.
*   **레이아웃 좌표:** 원형 또는 대칭 구도를 사용하여 중심점(Order)을 강조.
*   **핵심 요소:** 복잡성(Red)이 단순함(Blue)으로 압축되는 과정을 시각적 흐름으로 표현.

## 3. [영상 C] 결과 및 최종 정리
*   **컨셉:** Blue가 지배적인 깔끔하고 정돈된 레이아웃. 모든 정보가 명확하게 분류되고 완결된 상태를 표현.
*   **레이아웃 좌표:** 그리드 기반의 완벽한 대칭 구조.
*   **핵심 요소:** 최종 결과물(Order)이 달성되었음을 시각적으로 확정.
