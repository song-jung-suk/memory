## 🎯 Project Overview

This repository systematically organizes the top 100 ChatGPT prompts for online sellers doing Chinese product sourcing (Taobao, 1688), buying agents, and bulk importers to double operational productivity.

### ✨ Features
- 📖 **100 Verified Prompts**: Specialized for global sourcing & purchasing agents
- 🌐 **Bilingual Support**: Korean + English complete translations
- 📁 **Categorized Organization**: Sourcing, SEO optimization, copywrite templates, CS, etc.
- 🎥 **YouTube Integration**: Video tutorials included
- 🔧 **Practical Templates**: Ready-to-copy formats

git clone https://github.com/song-jung-suk/connect-ai.git

- English: Check `english/` folder
